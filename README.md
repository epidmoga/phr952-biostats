# PHR 952 Biostatistics — Interactive Teaching Tools

Two browser-based tools for teaching statistical test selection to
pharmacy students. No installation, no dependencies — open the HTML
file in any modern browser.

## Live tools

- **[Statistical Test Selector](https://epidmoga.github.io/phr952-biostats/decision_tool.html)**
- **[Practice Scenarios](https://epidmoga.github.io/phr952-biostats/practice_scenarios.html)**

## The tools

**Statistical Test Selector** (`decision_tool.html`)
An interactive decision tree that walks students through choosing the
correct statistical test. Students answer questions about their data
(number of variables, data type, distribution, paired vs. independent)
and arrive at a recommended test with assumptions, worked clinical
examples, and references.

**Practice Scenarios** (`practice_scenarios.html`)
18 clinical scenarios of varying difficulty. Students work through the
same decision logic against real research questions and receive
immediate feedback. Filter by difficulty or shuffle for repeat practice.

## Using these in your course

Both files are self-contained. You can:
- Open them directly from a local copy
- Upload to your LMS (Canvas, Blackboard) as an HTML file
- Host them on any static web host and link from a syllabus
